# Security Policy

AdaptNXT takes the security of our open-source tools and industrial software seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not report it publicly via GitHub Issues.**

Instead, report vulnerabilities privately by emailing:
📧 **queries@adaptnxt.com** with the subject line `[SECURITY] Modbus Telemetry Encoder Vulnerability`.

Please include:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce or proof-of-concept script.
3. Affected software versions and runtime environment.

### Our Commitment
- We will acknowledge receipt of your report within **48 hours**.
- We will provide an estimated timeline for a patch.
- Once fixed, we will credit you in our [CHANGELOG.md](CHANGELOG.md) (unless you request anonymity).
